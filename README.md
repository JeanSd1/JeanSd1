## Projetos em Destaque

- **[ADA-V2](https://github.com/JeanSd1/ADA-V2)** 🐍 Python / React / Electron
  - Assistente de IA multimodal com Gemini 2.5 Native Audio, visão computacional, controle por gestos e geração de modelos CAD 3D. Integra autenticação facial, automação de navegador via Playwright, impressão 3D e controle de Smart Home (TP-Link Kasa). Interface estilo "Minority Report" com MediaPipe para rastreamento de mãos.
